# v364：接通 Claude 现有二进制的百万上下文，清理执行过程噪声

这是待用户真机验收的 test 通讯包，不提升稳定标签、不更换 v362 救援基线。没有升级任何 CLI，不修改正式历史或手机当前配置，APK 只在 GitHub Actions 构建。

## 已查明并纠正的能力判断

当前 Claude 2.1.97 的 `TV(model)` 默认窗口为 200000，但原生 `[1m]` 标识返回 1000000，发送到上游时会移除该标识。它不认识 `CLAUDE_CODE_MAX_CONTEXT_TOKENS`，因此只填写数字不生效；二十万并非 CLI 不可突破的硬上限。MiniMax 官方 Anthropic API 文档列出 M3 的百万窗口，官方 Claude 文档说明了标识和去除行为。最新官方文档包含更晚版本的环境变量能力，不把它误套到当前 2.1.97。

2026-10-12 用当前已安装二进制和用户现有 MiniMax-M3 做只读隔离实测：小请求握手成功，实际 275204 输入请求成功，实际 900235 输入请求成功，三次均报告 `contextWindow=1000000`。长请求正确返回开头、中间、结尾三个标记。只读本地转发观察到上游仍为 `MiniMax-M3`，没有把 `[1m]` 当作提供商新模型名，没有关闭原生压缩或改写二进制来绕过测试。测试临时配置与正式会话、认证、参数分离，正式三文件哈希不变。完整证据在本地诊断目录 `v364_Claude百万上下文_真实验收_20261012.json`。

## 实现范围

新增 Kotlin 能力解析器，并与自然语言配置工具中的纯 JS 解析器保持测试覆盖。仅在准确 MiniMax-M3 和当前真实验证的 HTTPS api.minimaxi.com/anthropic 路线启用百万能力，不按模糊模型名把任意网关称作已验证。其他域名即使也是提供商官方区域地址，也不冒用本次账户和网络路线的实测证明；未来可以独立验证后加入。

零上下文配置在该路线自动采用百万窗口。旧故障参数组合 524288/512000/514000 自动在运行时恢复为百万窗口，不重写用户保存的正式值；主动选择的较小窗口仍尊重。CLI 启动加 `[1m]`，输入保护、输出预算和自动压缩同时使用解析后的窗口，不能只把标签或页面数字改大。当前 CLI 通用输出上限按 128000 处理，本应用另保留四分之一安全比例；百万上下文包含输入与输出，不表示一百万输入再加任意输出。旧参数组合输出预算 128000，主动阈值 706320；通常 32768 输出预算主动阈值 783457。容量和主动阈值不是同一个概念。

模型管理显示实际运行预算，编辑页面随模型、地址和参数变化解释能力与限制，拒绝超过当前路线预算的保存。显示当前自然语言运行覆盖值，不再只显示底层旧存储值；用户手动保存或切换当前模型时清理旧运行覆盖字段，避免保存的新设置被旧覆盖遮住。此动作仅发生在用户操作时，不在覆盖安装或本轮开发期间执行。

自然语言工具 get、update、reset 返回 `runtimeCapabilities`，包含实际窗口、输出、主动阈值、CLI 模型标识和能力说明。显式请求超出窗口或输出预算会拒绝且不落盘。给模型的工具描述和系统工具说明要求先读取能力，不能把保存成功宣传成扩容。正式公有目录仅新增无密钥的 baseUrl 供路由识别，认证从不写入公有目录。

执行过程不再每轮写上下文或输出技术说明，不渲染 `stream_event`、`user`、初始化等通信噪声；真正的工具调用、进度、压缩完成和错误保留。修正活跃列表与目标列表相同时同一条状态被追加两次。历史执行记录只在显示层过滤这些噪声，不重写、删除或迁移会话内容。

## 验证与交付要求

新增 Node 能力测试与真实 MCP get/update/reset 往返测试，验证超限失败不写配置、未知网关不能冒用证明、旧预算修复、显式较小窗口以及显示噪声处理。新增 Android JVM 能力与显示去重测试。既有真实模型压缩 worker 不变，保留 v363 的模型重试和分片恢复。

安装 v364 不需要更新 Claude。原 Claude 会话继续发送，执行过程不再出现重复前缀和底层事件，原有思考、工具及错误仍可见。模型管理和自然语言只读配置查询应显示当前 M3 官方路线百万窗口，修改超出已支持范围时应明确说明而不是虚假成功。正常长任务应使用新预算而非二十万宿主上限；手动及自动真实模型压缩、重启历史、Codex 模型切换与其他智能体均须真机回归。此时才考虑提升稳定版，不在开发者测试后直接冒称用户验收完成。

v362 的独立高版本救援 APK 保持原件并可覆盖 v364，但会恢复旧业务行为，包括此次修复之前的 Claude 预算和压缩问题。不得卸载、清数据、热更新正式 CLI、删除原历史或为测试切换用户模型。

官方参考：https://code.claude.com/docs/en/model-config 与 https://platform.minimax.io/docs/api-reference/text-anthropic-api 。完整构建身份、安装包哈希与交付路径另记本地紧急接管交接文档。
