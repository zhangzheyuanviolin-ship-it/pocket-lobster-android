# 口袋大龙虾 v341 产品总览

日期：2026-09-05

## 产品定位

口袋大龙虾是一套面向 Android 的多智能体工作平台。它的目标是让一台普通、非 root 的 ARM64 手机同时承担个人 AI 助手、开发工作站、文件处理终端、网页操作环境和手机自动化设备的角色。

项目的核心不是智能体数量，而是让不同智能体在同一宿主中拥有真实、稳定、可验证的执行环境。用户可以根据任务选择最合适的智能体，也可以让三个通用智能体协作。每项重要能力都同时考虑后台持续运行、会话恢复、共享工具、任务审计和屏幕阅读器交互。

## 用户可以怎样工作

### 独立任务

用户直接进入 Codex、Claude Code 或 Minis 的聊天页面。每个智能体维护自己的会话、上下文和模型配置，可以独立接收多轮任务并调用终端、浏览器、共享文件或网络工具。用户可以在不同智能体页面之间切换，后台前台服务负责维持正在运行的工作。

### 三智能体协作

用户在任意一个主智能体页面打开三智能体协作，让当前智能体担任总调度。总调度读取用户目标，判断是否需要成员参与，并生成明确的子任务。成员完成后把结果交回总调度，总调度进行事实核验、冲突处理和最终汇报。

用户通过统一协作看板查看全过程。看板把每轮用户消息、总调度角色、成员任务、成员结果、最终回复和终态分开显示。长内容默认可折叠，输入区固定，历史任务可管理、导出和分享。

### 手机操作

用户进入手机操作智能体，选择主屏幕或虚拟屏幕，设置最大步骤并发送自然语言任务。主屏幕模式直接操作用户当前屏幕；虚拟屏幕模式在隔离显示器中启动目标应用，减少对用户当前操作的打扰。

宿主把截图和任务交给视觉模型，把模型动作转换为 Android 操作，然后把新画面送回模型继续判断。输入文字后宿主主动处理键盘收起；滚动动作兼容坐标式和方向式输出；格式异常会携带具体原因反馈给模型并重试。只有密码、一次性验证码、CAPTCHA 或生物识别等必须由用户完成的环节才需要接管。

手机操作智能体在 v341 中保持手动启动。三个主智能体不暴露调用它的工具，避免任务语义、屏幕状态和用户授权在跨智能体转发中失真。

## 四个智能体的互补关系

Codex 是工程执行核心。它最适合代码库理解、修改、测试、版本控制、构建、发布和复杂终端任务。它可以使用 OpenAI 账户授权或 Responses 兼容提供商，并在会话中切换模型和推理强度。

Claude Code 是工具编排与长文本分析核心。它适合复杂代码分析、资料处理、系统排查和跨工具任务。它拥有独立模型管理，支持 Anthropic 官方接口、阿里云 Coding Plan 和自定义 Anthropic 兼容服务。

Minis 是移动原生通用智能体。它基于 OpenMinis 1.12，拥有独立聊天、权限和提供商管理，并提供真实可见浏览器与轻量 Alpine 环境。它与口袋大龙虾宿主共享终端和浏览器桥。

手机操作智能体是视觉执行器。它不承担代码仓库和多智能体调度，而是专注于观察 Android 页面、选择动作、输入文字、滚动、启动应用和完成界面任务。它可以使用专门训练的手机模型，也可以使用能够遵循通用 JSON 动作协议的视觉语言模型。

## 执行环境

Android 本地终端运行在应用私有目录，提供 Node.js、Python、Git、curl、ripgrep 等工具，并可以访问用户授权的共享存储。它最接近应用真实运行环境。

Ubuntu 24.04 通过 PRoot 运行，提供完整 Linux 用户空间、apt 包管理和常规开发工具。它适合需要标准发行版依赖的构建、脚本和数据任务。

Alpine 运行时来自 OpenMinis，启动快、体积较轻，适合隔离命令和简单 Linux 工作负载。

system-shell 由 Shizuku 提供 Android shell 身份，用于设备属性、系统服务、包状态和授权范围内的系统命令。它不等同于 root，也不绕过 Android 权限边界。

共享存储是跨运行时交换用户文件和交付成果的主要通道。智能体私有会话、密钥和运行状态保留在各自应用私有目录中。

## 浏览器

真实浏览器基于 OpenMinis WebView。它支持标签页、导航、点击、输入、滚动、DOM 文本、可读正文、元素查询、JavaScript、Cookie、截图和用户接管。浏览器运行在独立 Minis 进程中，避免主进程和 WebView 同时使用同一数据目录造成锁冲突。

Codex、Claude Code 和 Minis 访问同一个标签池。显式指定 tabId 可以继续其他智能体创建的页面；宿主对显式标签动作串行化，降低并行操作冲突。截图会保存到智能体可读取的位置，并能交给图像查看工具分析。

## 模型与协议

Codex 使用官方 Codex CLI。权限管理页负责安装和修复锁定版本，避免把 CLI 固定打进 APK。当前锁定版本是0.153.4。Codex 支持官方账户授权和 Responses 兼容提供商。

Claude Code 支持 Anthropic 协议，模型配置包含提供商名称、Base URL、API 密钥和模型 ID。

Minis 使用 OpenMinis 的模型提供商体系。

手机操作智能体支持三种协议：AutoGLM Native、GUI Plus Native 和 Generic JSON。Generic JSON 解析器兼容动作别名、代码围栏、tool_calls、function_call、不同大小写以及多种 Swipe 表达。不同协议拥有独立纠错次数，错误消息包含 requestId、finishReason、推理长度和原始输出摘要，便于区分模型格式问题与提供商超时。

## 稳定性设计

Codex 聊天使用乐观消息、临时线程、快照恢复和定时同步，避免消息已经执行但前端暂时不可见。Claude 与 Minis 使用独立会话存储。协作运行拥有稳定 runId、轮次记录、角色状态和终态，升级后可以恢复历史任务而不依赖旧进程句柄。

前台服务维持 Codex 与宿主运行；Minis 浏览器和运行时使用独立进程；WebView 数据目录按进程隔离。Shizuku 支持多进程 Binder 获取。浏览器、终端和协作接口使用本地令牌保护，只监听回环地址。

## 无障碍设计

项目的主要验证者使用 Android 屏幕阅读器，因此无障碍不是后补功能。聊天内容按单条消息聚焦；终端原始输出默认不挤占聊天主线；任务评论与最终回复分开；协作成员、角色、任务和结果按区块呈现；长内容支持收起；输入框和主要动作保持可达；历史导航提供明确按钮；危险删除操作要求二次确认。

手机操作智能体的进度变化不强制屏幕阅读器逐步播报，用户可以在需要时主动读取。

## 典型场景

开发者可以让 Codex 维护仓库、运行测试、触发云端构建和管理Release。资料工作者可以让 Claude 整理大量文档并调用Linux工具。普通用户可以让 Minis 使用真实浏览器检索和处理网页。需要操作第三方 Android 应用时，用户可以交给手机操作智能体在虚拟屏幕中执行。

协作模式适合需要多视角审查、并行调查、代码与文档同时产出、事实交叉核验或由一个智能体统一验收的任务。简单问候和单步任务可以由总调度直接回复，不强制启动所有成员。

## 当前边界

三个主智能体共享浏览器和终端，但并发操作同一标签页或同一文件仍需要任务层面的边界。虚拟屏幕是否能显示某个第三方应用取决于该应用、Android系统和图形栈。登录、验证码和生物识别可能要求用户接管。厂商的一键清理可以强制终止后台进程。模型能力、延迟和格式稳定性由用户选择的提供商决定。

## 项目价值

口袋大龙虾证明了一条可行路线：移动端智能体不必停留在聊天层。通过原生宿主、可验证的本地执行环境、受控系统权限、真实浏览器、协作协议和面向无障碍的交互，一台普通 Android 手机可以成为持续运行、可扩展并能交付真实成果的个人 AI 工作站。
